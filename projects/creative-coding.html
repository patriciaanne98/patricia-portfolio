01 / OVERVIEW

Code as a Creative Medium

Creative Coding is a collection of digital experiments exploring how programming can be used beyond traditional applications to create expressive visual experiences.

Through generative patterns, animation, mathematical relationships, and visual experimentation, this project explores the connection between technical problem-solving and creative thinking.

02 / SELECTED WORK

Digital Experiments

Interactive explorations of nature, technology, material, and motion through code.

01 / EXPERIMENT

Fragmented Matter

An interactive three-dimensional sculpture exploring fragmentation, movement, and reconstruction through mathematical patterns.

Click the sphere to shatter and reconstruct.
02 / EXPERIMENT

Orbital Systems

An interactive visualization of over 16,000 satellites using public orbital data, mathematical modeling, and real-time position calculations to explore the infrastructure surrounding Earth.

Drag to rotate, hover to explore, and filter by satellite category.
03 / EXPERIMENT

Digital DNA

An interactive molecular sculpture transforming real human DNA sequence data into a flowing, iridescent double helix through computational geometry and generative animation.

Hover over the molecules to explore nucleotide composition and complementary base pairs.
03 / REFLECTION

Beyond the Visual

Creative coding introduced me to a different way of approaching programming. Instead of focusing only on functionality, I explored how code could communicate ideas through movement, structure, and visual expression.

This collection reflects the relationship between experimentation, problem-solving, and design. It also demonstrates how technical and creative thinking can work together to create meaningful digital experiences.
